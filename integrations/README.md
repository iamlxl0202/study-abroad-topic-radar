# Skill 集成说明

本项目已将三个用户提供的 Skill 的核心合同接入网页工作流：

- `edu-digest`：近7天留学资讯，逐条读取原文并区分本周新增、申请提醒、待核实线索。
- `study-abroad-content-topics`：固定输出5个已核实时事选题和5个常青选题。
- `wechat-article-studio`：广州新东方留学官号文章，输出5组标题摘要、正文、单一CTA和编辑备注。

## 真实性边界

热榜仅用于发现线索。政策、费用、申请要求和截止时间必须回到政府、院校或主办方原文核验。未完成核验时，`data/weekly-report.json` 保持空资讯状态，不自动填充旧闻或模型猜测。

## 模型密钥

GitHub Pages 是公开静态网页，禁止在前端写入模型或公众号密钥。后续模型生成通过 GitHub Actions Secrets 或私有服务端接入；当前文章工作台提供不依赖密钥的可编辑规则草稿。
